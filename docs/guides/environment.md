# v1.0 环境清单

> 本清单基于实际执行环境查询结果整理（2026-11-12）。系统全程在本机运行，不依赖外部数据库、真实 SSO、短信或公众号服务。

## 1. 运行环境

| 项目 | 实际值 / 说明 |
|---|---|
| 操作系统 | Microsoft Windows 11 家庭版 中文版，64 位（内核版本 10.0.26200；兼容 Windows 10/11 64 位） |
| 运行时 | Python 3.13.14 |
| Web 框架 | Flask 3.1.2 |
| WSGI/工具依赖 | Werkzeug 3.1.4 |
| 测试框架 | pytest 9.2.0 |
| 数据库 | SQLite 3.50.4（Python 内置 `sqlite3`，无需额外安装数据库） |
| 浏览器 | Microsoft Edge 155.0.4283.45（正式版，64 位） |
| 服务端口 | 5012 |
| 资源要求 | 内存/磁盘无特殊要求；首次启动自动创建 `data\app.db` |

## 2. 依赖安装

在 `system\v1.0` 目录执行：

```powershell
python -m pip install -r requirements.txt
```

## 3. 启动与测试

启动：

```powershell
python app.py
```

也可在最终提交包根目录双击 `启动系统.bat`，脚本会自动切换目录、检查/安装依赖、启动服务并打开浏览器。

测试：

```powershell
python -m pytest -q
```

预期结果：**128 passed**。

## 4. 首次启动

首次启动自动创建 `data\app.db`，并写入 1 个自习室、3 个区域、10 个座位、28 项规则参数，以及学生、自习室管理员、系统管理员、后勤部门四个测试账号。

## 5. 故障处理

| 现象 | 处理方式 |
|---|---|
| 提示找不到 `python` | 安装 Python 3.13，并在安装时勾选“Add python.exe to PATH”；重新打开终端或重启资源管理器后重试 |
| 端口 5012 被占用 | 关闭其他正在运行的本系统实例；可用 `netstat -ano \| findstr :5012` 找到占用进程，确认后结束该进程 |
| 依赖安装失败 | 检查网络/代理配置后重试：`python -m pip install -r requirements.txt`；也可改用可访问的 PyPI 镜像源 |
| 需要重置演示数据 | 停止服务后删除 `v1.0\data\app.db`，再次启动会自动重建数据库并写入 seed 数据 |
| 浏览器未自动打开 | 服务启动后手动访问 <http://127.0.0.1:5012/> |

## 6. 部署边界

- 不依赖外部数据库；
- 不接入真实统一身份认证（SSO），使用本地模拟账号；
- 不发送短信、公众号或其他外部消息，通知仅保存在系统内；
- 全程在本机运行，登录、预约、扫描、统计与审计均为单机演示实现。
