## 3. 最终版演示路径

### 3.1 参数配置

1. 系统管理员登录，进入“参数配置”（`/sysadmin/params`）。
2. 页面列出 28 项规则参数的当前值、默认值、声明范围、来源性质、确认状态与最近变更时间。
3. 修改某一参数并保存：
   - 值必须落在声明范围，例如 `data_refresh_seconds` 只能在 5—60 秒；
   - 超出范围返回 400 `PARAM_OUT_OF_RANGE`，原值不变。
4. 保存成功后参数即时生效；例如把 `checkin_late_minutes` 从 15 调整为 25，此后签到时间窗按 25 分钟判定。
5. 系统管理员的“审计日志”可按“参数变更”筛选，查看变更人、时间、参数键、变更前后值。
6. 参数变更不回溯修改已生成的历史违约记录、计数或投诉；历史判定保持原状态。

对应 AC-13-01—AC-13-04。

### 3.2 评价与投诉演示

1. 学生登录，在 `/seats` 预约、在 `/usage` 签到并签退，使该预约变为「已完成」。
2. 学生进入 `/evaluations`，选择该已完成预约对应的座位提交评分与评论。
3. 学生对同一座位再次提交评价：服务端返回 409 `ALREADY_EVALUATED`，演示重复评价被拒绝。
4. 学生进入 `/complaints` 提交投诉，对象类型选择「其他用户」，填写被投诉学生学号（演示库仅一名学生时可用 `246003384` 验证脱敏输出）及投诉类型、内容。
5. 自习室管理员进入 `/admin/complaints`，先点击「受理投诉」，填写反馈内容并提交；投诉状态依次推进为「处理中」「已回复」。
6. 学生回到 `/complaints` 查看反馈；被投诉学生姓名、学号、联系方式以脱敏形式显示。
7. 学生点击「申请复核（仅一次）」提交复核；投诉回到「处理中」，再次申请复核会被拒绝。
8. 管理员进入 `/admin/evaluations`，选中此前提交的评价，填写理由后点击「隐藏评价」；评价不再计入平均分与条数。

覆盖评价与投诉主要链路（AC-08、AC-09）。

### 3.3 全量功能

- 学生：预约、预约修改（跨自习室、最多一次）、取消、签到/签退、违约申诉、信用、记录查询、评价、投诉、通知、本人联系方式。
- 自习室管理员：资源维护、代创建预约、实时座位、V3、提前释放、历史、申诉、黑名单直接加入/延期、投诉驳回/反馈、扫描、评价隐藏、分析、通知。
- 系统管理员：审计日志、参数配置、用户查询、管理员授权维护、数据分析、CSV 导出。
- 后勤部门：只读数据分析、CSV 导出与记录查询。
