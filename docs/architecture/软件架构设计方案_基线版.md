## 0 基线与关闭状态

### 0.1 本基线采用的架构结论

1. 单进程 Flask 单体：26 个页面路由 + 41 个 JSON API，服务端渲染与同源 fetch 混合（ADR-01 暂缓拆分、ADR-03 接受 A）。
2. 单个 SQLite 文件库：WAL、`BEGIN IMMEDIATE`、数据库触发器兜底；单写者，写入吞吐有上限（ADR-02、Q-24）。
3. 违约判定、黑名单到期、投诉自动关闭、提醒由进程内守护线程执行；固定单进程，禁止多 worker（ADR-04、Q-25）。
4. 应用层 + 触发器双保险维护预约重叠、违约去重、审计与通知不可改删（ADR-05）。
5. 参数默认值在 `config.py`，运行时读 `rule_params`；补“缺失参数补种”作为接受条件，但 2026-11-12 验证未通过（未补种），风险接受（ADR-06）。
6. 认证为模拟 SSO，本地账号 + 密码哈希，写明替换点；真实适配层不实现（ADR-08、Q-44）。
7. 审计防篡改为应用层拒绝 + 触发器；只读账号/哈希链不在本期（ADR-07）。
8. 部署为单机演示：`127.0.0.1:5008`、Flask 开发服务器、无外部数据库/SSO/消息通道、无定时备份（Q-21、Q-23 已关闭）。

## 2 运行视图

```text
┌──────────────────────────────┐
│ 浏览器（Edge / Chrome）        │
│ Jinja2 页面 + 内联 JS fetch    │
└──────────────┬───────────────┘
               │ HTTP 127.0.0.1:5008
               │ Cookie: Flask 签名会话
┌──────────────▼───────────────┐
│ Flask 开发服务器（单进程）      │
│ app.run(host=127.0.0.1)       │
│                               │
│ ├─ 26 个页面路由              │
│ ├─ 41 个 JSON API 路由        │
│ ├─ 业务函数（app.py 内）       │
│ ├─ 守护线程 zxss-maintenance  │
│ │    每 P-15 秒执行扫描        │
│ └─ sqlite3（每请求一个连接）   │
└──────────────┬───────────────┘
               │ 文件 I/O（WAL）
┌──────────────▼───────────────┐
│ data/app.db                   │
│ 14 张表 + 5 个触发器           │
└──────────────────────────────┘
```

| 项目 | 基线口径 | 依据 |
|---|---|---|
| 监听地址 | `127.0.0.1:5008` | `config.py:19-20` |
| 服务器 | Flask 内置服务器，`debug=False` | `app.py:5012` |
| 进程模型 | 单进程；一条守护线程；**禁止多 worker** | Q-25、ADR-04 |
| 数据库 | SQLite 文件，WAL，`busy_timeout=30s` | Q-24、ADR-02 |
| 并发写 | `BEGIN IMMEDIATE` 串行化 + 触发器兜底 | ADR-05 |

| 外部依赖 | 无外部数据库、无真实 SSO、无短信/公众号 | Q-11、Q-21 |

## 3 逻辑架构

### 3.1 分层

| 层 | 载体 | 基线职责 | 约束 |
|---|---|---|---|
| 表现层 | `templates/*.html`（26）、`static/*.css`（7） | 服务端渲染；页面内联 JS 调 JSON API；统计 10 秒轮询 | 不做前端构建；关键操作仅前端 `confirm`（Q-37） |
| 接口层 | `create_app()` 内 67 个路由 | 参数解析、内容协商、角色校验、错误映射 | 页面与 API 双出口；不新增已移出范围的接口 |
| 业务层 | `app.py` 内 94 个模块级函数 | 预约、签到、违约、黑名单、资源、投诉、评价、统计 | 依赖 Flask 上下文；不拆分（ADR-01 暂缓） |
| 数据访问层 | `db.py` + 业务函数内联 SQL | 连接、事务、参数读取、审计写入、建库 | 无 Repository 抽象；SQL 分散 |
| 配置层 | `Config` + `rule_params` 表 | 端口、密钥、库路径；28 项业务参数 | 双源 + 缺失参数补种（ADR-06 验证未通过，风险接受） |
| 后台任务 | `start_scheduler()` 守护线程 | 状态推进、V1/V2、黑名单到期、投诉自动关闭、提醒 | 固定单进程；禁止多 worker |
| 测试 | `tests/` 19 个测试文件 | Flask test_client + 临时库 + 假时钟 | 83 passed；并发测试未执行 |

### 3.2 模块与基线口径

| 模块 | 关键函数 | 基线口径 |
|---|---|---|
| 认证与会话 | `authenticate_user`、`login_required`、`role_required` | 锁定 5 次/15 分钟；空闲 30 分钟；无服务端单会话 |
| 座位查询 | `query_seats`、`_free_time_ranges` | 返回当前展示状态与时段可约性；状态不代表逐时段占用 |
| 预约 | `create_reservation` | 上限 1；单段；自然日；不跨日；无幂等键；无管理员代创建 |
| 取消/签到/签退 | `cancel_reservation`、`checkin_reservation`、`checkout_reservation` | 取消不限次数；窗口起点推进；无时段修改 |
| 违约/申诉 | `_create_auto_violation`、`submit_violation_appeal`、`adjudicate_appeal` | 单条违约终结；无附件；计数永久累计 |
| 黑名单 | `maybe_apply_blacklist`、`expire_blacklists`、`release_blacklist` | 自动/到期/提前解除；无直接加入/延期；解除不清零 |
| 资源 | `create_room`、`create_zone`、`create_seat`、`disable_seat`、`restore_seat` | 新增/停用/恢复；授权由 seed 与创建者获得；停用不终止当前使用 |
| 实时与 V3 | `realtime_snapshot`、`manual_violation`、`admin_release_reservation` | 脱敏；V3 无预约时必须提供学号 |
| 记录与审计 | `query_reservations_scoped`、`query_audit_logs` | 角色隔离、分页；审计只读 |
| 参数 | `list_rule_params`、`update_rule_param` | 28 项；范围校验；页面标注生效点；P-15 目标 10—60 秒 |
| 评价 | `submit_evaluation`、`hide_evaluation` | 实名；真实使用；去重；隐藏不计分 |
| 投诉 | `create/accept/feedback/review/auto_close` | 四态；复核一次；无 ST-25/27；无超期提醒；不强制回避 |
| 统计 | `analytics_data` | 自习室 + 日粒度；10 秒刷新 |
| 通知 | `notify_user`、`query_notifications` | 系统内；事件去重；无接近阈值提醒 |
| 横切 | 脱敏、权限、时钟、事务 | 服务端校验；`get_now()` 统一时钟 |

### 3.3 横切机制

| 机制 | 基线实现 | 已知限制 |
|---|---|---|
| 会话 | `before_request` 装载用户；空闲超时读 P-17；`session.clear()` 跳登录 | 无服务端会话表；同一学生可多端登录（Q-37） |
| 角色权限 | `role_required` + `require_room_access`/`require_seat_access` | 系统管理员资源权限已在 v0.8 按矩阵放开（R-13 已解决） |
| 错误处理 | `ApiError` + 统一 JSON/HTML 错误体 | 无错误码字典的机器可读约束 |
| 审计 | 与业务写同事务；触发器禁改删 | 有文件写权限者可绕过（ADR-07） |
| 参数 | 运行时读 `rule_params`；缺失参数补种（验证未通过） | 15 项已接入、13 项未接入；P-15 为 10—60 秒 |
| 时间 | `get_now()`；测试注入 `NOW_PROVIDER` | 无时区/夏令时处理 |
| 脱敏 | 姓名、学号、联系方式输出层脱敏 | 导出未实现；日志未记录敏感字段 |
| 事务 | `BEGIN IMMEDIATE` | 单写者排队；高并发会超时 |

## 4 数据架构

### 4.1 表清单（14 张，无新增）

| 表 | 作用 | 基线约束 |
|---|---|---|
| `users` | 账号、角色、账号状态、锁定/黑名单、有效违约计数 | 学号唯一；账号状态单字段 + `pre_lock_status`（Q-40） |
| `rooms` | 自习室、开放时间、状态 | 编号唯一；`open_to > open_from` |
| `zones` | 区域、类型、排序 | 同一自习室编号/名称唯一 |
| `admin_room_assignments` | 管理员授权范围 | 管理员 + 自习室唯一；无维护界面（Q-46） |
| `seats` | 座位、类型、状态、是否可约 | 编号唯一；状态仅展示（Q-33） |
| `reservations` | 预约单、时段、状态、来源 | 单号唯一；结束晚于开始；状态六值 |
| `checkins` | 签到/签退与实际时长 | 预约单唯一；时长 ≥ 0 |
| `violations` | V1/V2/V3 与申诉状态 | 单号唯一；同预约同类型唯一（BR-11） |
| `blacklists` | 黑名单记录、来源、期限、解除 | 状态三值；无直接加入/延期 |
| `notifications` | 系统内通知、已读、送达结果 | 事件键唯一；删除触发器拒绝 |
| `evaluations` | 评分、评论、隐藏 | 同一用户 + 对象唯一；评分 1—5；实名 |
| `complaints` | 投诉单、处理人、反馈、复核 | 单号唯一；四态；复核 0/1 |
| `audit_logs` | 操作审计、前后值、结果、IP | UPDATE/DELETE 触发器拒绝 |
| `rule_params` | 28 项参数、默认值、范围、来源 | 键/编号唯一；P-15 目标 10—60 秒 |

### 4.2 关键不变量

| 不变量 | 应用层 | 数据库层 |
|---|---|---|
| 同一座位同一日期时段至多一条有效预约 | `BEGIN IMMEDIATE` + 冲突 SELECT | `trg_reservations_no_overlap_insert/update` |
| 同预约同违约类型不重复 | 先查后插 | `uq_violations_reservation_type` |
| 通知不可删除 | DELETE 路由 403 | `trg_notifications_no_delete` |
| 审计不可改删 | PUT/PATCH/DELETE 路由 403 | `trg_audit_logs_no_update/delete` |
| 座位状态只由流程驱动 | 写入点受控 | 无触发器；直连 SQL 仍可改 |
| 账号状态与黑名单一致 | 自动加入/到期/解除函数 | 无触发器 |

### 4.3 状态模型基线口径

| 状态机 | 基线口径 | 与 SRS 的差异 |
|---|---|---|
| SM-01 座位 | 状态仅展示；预约可行性按时段冲突；停用不终止当前使用 | BR-03 待改写；ST-08 当前使用保留 |

## 5 接口架构

### 5.1 规模与约定

- 路由总数 67：页面 26、JSON API 41；其中 4 个显式拒绝端点（直接改座位状态、改删审计、删通知、旧版手动违约路径）。
- 成功返回 JSON 业务对象；失败返回 `{"error":{"code","message"}}`；状态码 400/401/403/404/409/410/423。
- 认证：Flask 签名 Cookie；无 CSRF Token，`SameSite=Lax`。
- 权限：角色装饰器 + 对象归属/自习室授权；服务端校验。
- 分页：记录默认 10、审计默认 20，上限 100。
- 无 API 版本前缀、无 OpenAPI、无请求 ID、无速率限制。

### 5.2 基线接口边界

| 能力 | 基线状态 | 说明 |
|---|---|---|
| 管理员代创建预约 | 不提供 | `POST /api/reservations` 仅学生；Q-26 |
| 预约时段修改 | 不提供 | 无接口；Q-27 |
| 黑名单直接加入/延期 | 不提供 | 仅自动/到期/提前解除；Q-28 |
| 投诉不成立关闭/确认关闭 | 不提供 | 仅受理/反馈/复核/自动关闭；Q-31 |
| 用户信息管理/用户查询 | 不提供 | 仅本人账号展示；Q-38 |
| 统计导出、申诉附件 | 不提供 | 扩展能力；Q-15、Q-16 |
| 外部通知 | 不提供 | 系统内消息；Q-11 |
| 服务端幂等键 | 不提供 | 依赖上限/唯一约束/前端禁用；EX-01 部分满足；Q-36 |
| 服务端单会话 | 不提供 | 仅前端 `confirm`；Q-37 |
| 系统管理员资源维护 | 已实现 | 权限矩阵第 15/16 行；v0.8 已按矩阵放开（Q-13、R-13 已解决） |
| 参数页 | 28 项 | 标注“生效点/未接入”；P-15 目标 10—60 秒；Q-18、Q-32 |

### 5.3 已同步的接口/需求语义

- `ST-11` 待签到推进时点、`BR-03` 可约条件、`UC-08/AD-03` 单条违约、`EX-01` 幂等缺口：接口行为已按决定实现，需求文本待 V1.4。
- 参数范围 P-15：v0.8 已实现 10—60 秒，参数页同步。
- 上述差异在 SRS V1.4 完成前不得写成“需求已满足”。

## 8 变更控制
