**填写规则**

1. “决定”列只由确认人填写，写可检验的规则，不写“按推荐”。
2. 每条决定需同时记录确认人、身份（真实/教学模拟）、日期、依据。
3. 推荐栏与决定栏冲突时，以决定栏为准，并在评审记录中说明理由。
4. 同一决定涉及多条 Q 时，只填主 Q，其余 Q 写“随 Q-xx”；本表已标出重复项。
5. 讨论稿 11.1 只列了 33 条 Q；其余 14 条按同一主题补入本表，编号后标 `†`。
